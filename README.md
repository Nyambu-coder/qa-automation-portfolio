# QA Automation Portfolio

A collection of QA testing and test automation projects that I am building as I develop my skills in test automation.

This portfolio documents my practical learning and experimentation with Cypress, Selenium, Playwright, and Postman.

## Projects

### Cypress Testing

Practice project focused on learning UI and API testing with Cypress.

Current areas of practice:

* Login flow testing using SauceDemo
* Homepage and navigation testing
* API requests using `cy.request()`
* GET and POST requests
* Basic error handling

[View Cypress Testing Repository](https://github.com/Nyambu-coder/cypress-testing)

### Selenium Testing

Practice project focused on learning browser automation with Selenium WebDriver and JavaScript.

Current areas of practice:

* Browser navigation
* Element interaction
* Basic automated test flows
* Screenshot capture

[View Selenium Testing Repository](https://github.com/Nyambu-coder/selenium-testing)

### Playwright Testing

Practice project focused on learning end-to-end testing with Playwright.

Current areas of practice:

* Basic end-to-end test flows
* Testing across Chromium, Firefox, and WebKit
* Screenshot capture
* Playwright's built-in auto-waiting

[View Playwright Testing Repository](https://github.com/Nyambu-coder/playwright-testing)

## Why These Projects?

I am currently developing my test automation skills and wanted to practice with several commonly used testing tools.

Working with different frameworks helps me understand:

* How automated tests are structured
* How browsers and web applications are tested
* How selectors and assertions are used
* How API testing fits into the QA process
* The differences between different automation frameworks

These repositories are learning projects, and I am continuing to improve them as my understanding and experience grow.
