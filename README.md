# QA Automation Portfolio

A collection of automated test suites demonstrating hands-on QA automation experience across the three major testing frameworks — Cypress, Selenium, and Playwright — plus API testing with Postman.

## Repositories

### 🌲 [Cypress Testing](https://github.com/Nyambu-coder/cypress-testing)
UI automation and API testing with Cypress.
- Login flow testing (Saucedemo)
- Homepage & navigation testing
- API testing via `cy.request()` (GET, POST, error handling)

### 🔵 [Selenium Testing](https://github.com/Nyambu-coder/selenium-testing)
Browser automation with Selenium WebDriver (JavaScript).
- Navigation and element interaction
- Screenshot capture (`driver.takeScreenshot()`)

### 🎭 [Playwright Testing](https://github.com/Nyambu-coder/playwright-testing)
Cross-browser E2E testing with Playwright.
- Runs identical tests across Chromium, Firefox, and WebKit
- Built-in screenshot automation
- Auto-waiting, no manual timing logic needed

## Why multiple frameworks?

Each tool has different strengths and is common in different hiring contexts:

| Tool | Strength |
|------|----------|
| Cypress | Fast, great DX, strong for modern JS apps |
| Selenium | Industry standard, widest language/browser support |
| Playwright | True cross-browser support, modern auto-waiting |

Having hands-on experience across all three means I can adapt to whatever stack a team already uses.
